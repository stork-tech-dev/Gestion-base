**Goal:** Caja por turnos (apertura, sumarse, retiros de efectivo, cierre con arqueo por medio de pago), notificación a los Admin cuando el arqueo da diferencia (con campanita en el header), y el turno abierto de hoy como requisito para confirmar y anular ventas.

**Architecture:** Igual que 02-06: API REST (`/api/v1/turnos`, `/api/v1/notificaciones`) con services sin commit, errores tipados y auditoría en la misma transacción; pantallas Jinja + un componente Alpine por pantalla. "Cuál es la caja" se responde SOLO en `services/turnos.py` (`obtener_turno_activo`, `turno_para_operar`). El esperado del arqueo lo calcula SOLO `services/arqueo.py::calcular_esperado` (el backend nunca confía en el del cliente). Concurrencia: quien opera (confirmar/anular venta, retiro, sumarse) toma el turno `FOR SHARE`; quien cierra lo toma `FOR UPDATE`.

**Tech Stack:** FastAPI, SQLAlchemy 2, Alembic (SQL a mano), PostgreSQL 15, Jinja2, Alpine.js 3, pytest, `node --test`.

**Spec:** `modulos/07_caja.md` + `CLAUDE.md` + `docs/pendientes.md` ("Para la sesión 07"). Donde este plan y el spec difieran, manda la sección "Decisiones y desvíos" de este plan.

## Decisiones y desvíos

Decisiones de producto tomadas con el usuario al inicio del módulo:

1. **Agrupación en terminal:** la migración siembra `medios_pago_arqueo_config` con "Débito" y "Tarjeta de Crédito" agrupados en `'Clover/Payway'`. Efectivo y Transferencia, línea propia cada uno. Nada informativo por defecto (el soporte de `es_informativo` se construye igual).
2. **Arqueo visible** (como el spec): Esperado | Declarado | Diferencia, con la diferencia calculada al tipear.
3. **Sumarse solo:** `turno_para_operar(db, usuario, ip)` suma al usuario a `turno_usuarios` si no estaba (audita `turno.unirse`). Así confirmar/anular venta y registrar retiro suman a quien opera. `unirse_a_turno` es el mismo camino.
4. **Campanita activa:** contador de no leídas + desplegable con las últimas notificaciones, "marcar como leída" al hacer clic y "Marcar todas como leídas". Los endpoints de `/api/v1/notificaciones` piden **solo sesión** (dependency nueva `requiere_login`), no `CAJA ver`: son las notificaciones propias del usuario.

Desvíos técnicos:

5. **"Hoy"** = fecha del negocio de `fecha_apertura`. Un turno abierto que pasa la medianoche queda "de día anterior" y bloquea (como dice el spec).
6. **`unirse_a_turno` exige turno de HOY** (usa `turno_para_operar`): sumarse a uno de un día anterior no tiene sentido; ese turno solo se puede cerrar.
7. **Concurrencia del cierre:** `turno_para_operar` bloquea la fila del turno `FOR SHARE` (y relee con `populate_existing`); `registrar_arqueo` la bloquea `FOR UPDATE`. Una venta que se confirma durante el cierre espera y, al liberarse, ve el turno cerrado → 409. Así ningún cobro queda en un turno ya arqueado.
8. **Abrir dos a la vez:** el índice `uq_turnos_un_abierto` es la garantía; `abrir_turno` inserta dentro de `db.begin_nested()` y un `IntegrityError` se traduce al 409 "Ya hay un turno abierto hoy…".
9. **Líneas del esperado:** medios **activos** + cualquier medio (aunque esté inactivo) con movimientos en el turno (si no, ese dinero desaparecería del arqueo). Orden: efectivo primero, después por nombre.
10. **Validación del arqueo:** cada línea no informativa debe declararse exactamente una vez (si falta → 400 "Falta declarar: …"); una línea que no existe en el esperado recalculado → 409 "Los medios de pago del arqueo cambiaron: volvé a cargar la pantalla."; `total_declarado` debe ser la suma de lo declarado en las líneas no informativas (si no → 400). Las informativas se guardan con `monto_declarado = monto_esperado` (diferencia 0), ignorando lo que mande el cliente.
11. **`GET /{id}/arqueo/esperado` de un turno cerrado → 409** "El turno ya está cerrado".
12. Respuestas con campos extra: `ArqueoLinea.es_efectivo` (la pantalla aclara "incluye $X de fondo inicial"); `ArqueoItemResponse.medio_nombre` (nombre del medio o del grupo); `RetiroResponse.usuario_nombre`.
13. **Sin cambios de permisos en la migración:** el seed de la sesión 02 (`migrations/seed.sql`) YA siembra `supervisor → caja ver+crear` y `vendedor → caja ver + caja.arqueo crear`. Solo se agrega un test que lo verifica.
14. `pesos_texto(valor)` en `core/utils.py` (formato "$ 1.500,00" / "-$ 1.500,00"), solo para el cuerpo de la notificación.

```python
"""Turnos de caja (sesión 07).

ÚNICO lugar que responde "cuál es la caja abierta" (obtener_turno_activo /
turno_para_operar). Para multi-local, estas funciones recibirían el local y
el resto del sistema no cambia.

Concurrencia: quien opera sobre el turno (venta, anulación, retiro, sumarse)
lo toma FOR SHARE; quien lo cierra (services.arqueo) FOR UPDATE. Una
operación que llega durante un cierre espera y ve el turno cerrado → 409.
"""
from datetime import date
from decimal import Decimal

from sqlalchemy import func, select
from sqlalchemy.dialects.postgresql import insert as pg_insert
from sqlalchemy.exc import IntegrityError

from app.core.auditoria import registrar_auditoria, snapshot
from app.core.errores import DatoInvalido, NoEncontrado, ReglaDeNegocio
from app.core.utils import ahora_db, normalizar_texto, paginar, rango_fechas
from app.models import EstadoTurno, RetiroEfectivo, Turno, TurnoUsuario

MENSAJE_SIN_TURNO = "No hay un turno de caja abierto."
MENSAJE_YA_ABIERTO = "Ya hay un turno abierto hoy. Usá 'Unirme al turno' para sumarte."
TAMANO_MAXIMO = 100


def es_de_dia_anterior(turno: Turno) -> bool:
    return turno.fecha_apertura.date() < ahora_db().date()


def _mensaje_dia_anterior(turno: Turno) -> str:
    return (f"Hay un turno del {turno.fecha_apertura:%d/%m/%Y} sin cerrar. "
            "Cerrá el turno anterior antes de continuar.")


def obtener_turno_activo(db) -> Turno | None:
    """El turno abierto (de hoy o de un día anterior), o None."""
    return db.scalar(select(Turno).where(Turno.estado == EstadoTurno.ABIERTO))


def obtener_turno(db, turno_id: int) -> Turno:
    turno = db.get(Turno, turno_id)
    if turno is None:
        raise NoEncontrado("Turno no encontrado")
    return turno


def bloquear_turno(db, turno_id: int, *, compartido: bool = False) -> Turno:
    """SELECT … FOR SHARE (compartido) o FOR UPDATE de la fila por id (sin
    joins: Postgres no bloquea el lado nullable de un LEFT JOIN) y relectura
    con populate_existing."""
    db.execute(select(Turno.id).where(Turno.id == turno_id).with_for_update(read=compartido))
    turno = db.get(Turno, turno_id, populate_existing=True)
    if turno is None:
        raise NoEncontrado("Turno no encontrado")
    return turno


def _sumar_usuario(db, turno: Turno, usuario, ip) -> None:
    """Agrega al usuario al turno si no estaba (ON CONFLICT: dos pestañas a la vez)."""
    nuevo = db.scalar(
        pg_insert(TurnoUsuario)
        .values(turno_id=turno.id, usuario_id=usuario.id, ingreso=ahora_db())
        .on_conflict_do_nothing(index_elements=["turno_id", "usuario_id"])
        .returning(TurnoUsuario.id)
    )
    if nuevo is None:
        return
    db.expire(turno, ["participantes"])
    registrar_auditoria(db, accion="turno.unirse", entidad="turno", entidad_id=turno.id, usuario_id=usuario.id,
                        estado_nuevo={"usuario_id": usuario.id}, ip_origen=ip)


def turno_para_operar(db, usuario, ip) -> Turno:
    """El turno abierto de HOY, bloqueado FOR SHARE hasta el fin de la
    transacción, con el usuario sumado (decisión 3). 409 si no hay turno o si
    quedó abierto uno de un día anterior (bloqueo duro)."""
    turno_id = db.scalar(select(Turno.id).where(Turno.estado == EstadoTurno.ABIERTO))
    if turno_id is None:
        raise ReglaDeNegocio(MENSAJE_SIN_TURNO)
    turno = bloquear_turno(db, turno_id, compartido=True)
    if turno.estado is not EstadoTurno.ABIERTO:  # se cerró mientras esperábamos el lock
        raise ReglaDeNegocio(MENSAJE_SIN_TURNO)
    if es_de_dia_anterior(turno):
        raise ReglaDeNegocio(_mensaje_dia_anterior(turno))
    _sumar_usuario(db, turno, usuario, ip)
    return turno


def abrir_turno(db, usuario, efectivo_apertura: Decimal, notas: str | None, ip) -> Turno:
    if efectivo_apertura is None or efectivo_apertura < 0:
        raise DatoInvalido("El efectivo inicial no puede ser negativo")
    activo = obtener_turno_activo(db)
    if activo is not None:
        raise ReglaDeNegocio(_mensaje_dia_anterior(activo) if es_de_dia_anterior(activo) else MENSAJE_YA_ABIERTO)
    ahora = ahora_db()
    turno = Turno(estado=EstadoTurno.ABIERTO, efectivo_apertura=efectivo_apertura, usuario_apertura_id=usuario.id,
                  fecha_apertura=ahora, notas=normalizar_texto(notas))
    try:
        # Savepoint propio: si otro abrió en paralelo, el índice
        # uq_turnos_un_abierto corta acá y la sesión sigue usable.
        with db.begin_nested():
            db.add(turno)
            db.flush()
    except IntegrityError as exc:
        raise ReglaDeNegocio(MENSAJE_YA_ABIERTO) from exc
    db.add(TurnoUsuario(turno_id=turno.id, usuario_id=usuario.id, ingreso=ahora))
    db.flush()
    db.refresh(turno)
    registrar_auditoria(db, accion="turno.abierto", entidad="turno", entidad_id=turno.id, usuario_id=usuario.id,
                        estado_nuevo=snapshot(turno), ip_origen=ip)
    return turno


def unirse_a_turno(db, usuario, ip) -> Turno:
    """Decisión 6: solo al turno de hoy. Si ya estaba sumado no hace nada."""
    return turno_para_operar(db, usuario, ip)


def registrar_retiro(db, usuario, monto: Decimal, motivo: str, ip) -> RetiroEfectivo:
    """El permiso (caja.retiro) lo exige el endpoint."""
    motivo = normalizar_texto(motivo)
    if not motivo or len(motivo) > 255:
        raise DatoInvalido("El motivo del retiro es obligatorio (hasta 255 caracteres)")
    if monto is None or monto <= 0:
        raise DatoInvalido("El monto del retiro tiene que ser mayor a cero")
    turno = turno_para_operar(db, usuario, ip)
    retiro = RetiroEfectivo(turno_id=turno.id, monto=monto, motivo=motivo, usuario_id=usuario.id,
                            timestamp=ahora_db())
    db.add(retiro)
    db.flush()
    registrar_auditoria(db, accion="caja.retiro_efectivo", entidad="retiro_efectivo", entidad_id=retiro.id,
                        usuario_id=usuario.id, estado_nuevo=snapshot(retiro), ip_origen=ip)
    return retiro


def listar_retiros(db, turno_id: int) -> list[RetiroEfectivo]:
    return list(db.scalars(select(RetiroEfectivo).where(RetiroEfectivo.turno_id == turno_id)
                           .order_by(RetiroEfectivo.timestamp, RetiroEfectivo.id)).all())


def listar_turnos(db, *, estado: EstadoTurno | None = None, desde: date | None = None, hasta: date | None = None,
                  pagina: int = 1, tamano: int = 20) -> tuple[list[Turno], int]:
    condiciones = rango_fechas(Turno.fecha_apertura, desde, hasta)
    if estado is not None:
        condiciones.append(Turno.estado == estado)
    pagina, tamano = paginar(pagina, tamano, TAMANO_MAXIMO)
    total = db.scalar(select(func.count()).select_from(Turno).where(*condiciones))
    turnos = db.scalars(select(Turno).where(*condiciones).order_by(Turno.fecha_apertura.desc(), Turno.id.desc())
                        .offset((pagina - 1) * tamano).limit(tamano)).unique().all()
    return list(turnos), total
```

```python
"""Arqueo y cierre del turno (sesión 07).

Se arquea POR TURNO, no por franja horaria: suma lo cobrado en ventas con
turno_id = el turno (confirmadas o anuladas después: el dinero entró acá) y
resta lo de ventas con turno_anulacion_id = el turno (el dinero salió acá).
El efectivo además suma el fondo inicial y resta los retiros.
"""
from collections import defaultdict
from dataclasses import dataclass

from decimal import Decimal

from sqlalchemy import func, or_, select

from app.core.auditoria import registrar_auditoria, snapshot
from app.core.errores import DatoInvalido, NoEncontrado, ReglaDeNegocio
from app.core.permisos import ROL_ADMIN
from app.core.utils import ahora_db, pesos_texto, sin_tildes
from app.models import (
    Arqueo, ArqueoItem, EstadoTurno, EstadoVenta, MedioDePago, MedioPagoArqueoConfig, Notificacion, RetiroEfectivo,
    Rol, TipoNotificacion, Turno, Usuario, Venta, VentaPago,
)
from app.services.turnos import bloquear_turno, obtener_turno

CERO = Decimal("0")
MENSAJE_CERRADO = "El turno ya está cerrado"


def clave_de(medio_de_pago_id: int | None, grupo_terminal: str | None) -> tuple:
    return ("grupo", grupo_terminal) if grupo_terminal else ("medio", medio_de_pago_id)


@dataclass
class LineaArqueo:
    medio_de_pago_id: int | None
    grupo_terminal: str | None
    medio_nombre: str
    es_efectivo: bool
    es_informativo: bool
    monto_esperado: Decimal

    @property
    def clave(self) -> tuple:
        return clave_de(self.medio_de_pago_id, self.grupo_terminal)


def _sumas_por_medio(db, *condiciones) -> dict[int, Decimal]:
    filas = db.execute(
        select(VentaPago.medio_de_pago_id, func.sum(VentaPago.monto_total))
        .join(Venta, Venta.id == VentaPago.venta_id).where(*condiciones).group_by(VentaPago.medio_de_pago_id)
    ).all()
    return {medio_id: monto for medio_id, monto in filas}


def _movimientos_por_medio(db, turno_id: int) -> dict[int, Decimal]:
    neto: dict[int, Decimal] = defaultdict(lambda: CERO)
    cobros = _sumas_por_medio(db, Venta.turno_id == turno_id,
                              Venta.estado.in_([EstadoVenta.CONFIRMADA, EstadoVenta.ANULADA]))
    anulaciones = _sumas_por_medio(db, Venta.turno_anulacion_id == turno_id, Venta.estado == EstadoVenta.ANULADA)
    for medio_id, monto in cobros.items():
        neto[medio_id] += monto
    for medio_id, monto in anulaciones.items():
        neto[medio_id] -= monto
    return dict(neto)


def _total_retiros(db, turno_id: int) -> Decimal:
    return db.scalar(select(func.coalesce(func.sum(RetiroEfectivo.monto), CERO))
                     .where(RetiroEfectivo.turno_id == turno_id))


def calcular_esperado(db, turno: Turno) -> tuple[list[LineaArqueo], Decimal]:
    """Una línea por medio activo (o con movimientos en el turno, decisión 9),
    o por grupo de terminal. total = suma de las líneas no informativas."""
    movimientos = _movimientos_por_medio(db, turno.id)
    medios = db.scalars(select(MedioDePago).where(
        or_(MedioDePago.activo.is_(True), MedioDePago.id.in_(list(movimientos))))).all()
    configs = {c.medio_de_pago_id: c for c in db.scalars(select(MedioPagoArqueoConfig))}
    lineas: dict[tuple, LineaArqueo] = {}
    for medio in medios:
        config = configs.get(medio.id)
        monto = movimientos.get(medio.id, CERO)
        if medio.es_efectivo:
            # El cajón físico incluye el fondo inicial.
            monto += turno.efectivo_apertura - _total_retiros(db, turno.id)
        informativo = bool(config and config.es_informativo)
        if config and config.agrupa_en_terminal and not medio.es_efectivo:
            nueva = LineaArqueo(None, config.grupo_terminal, config.grupo_terminal, False, informativo, CERO)
        else:
            nueva = LineaArqueo(medio.id, None, medio.nombre, medio.es_efectivo, informativo, CERO)
        linea = lineas.setdefault(nueva.clave, nueva)
        linea.monto_esperado += monto
    ordenadas = sorted(lineas.values(), key=lambda l: (not l.es_efectivo, sin_tildes(l.medio_nombre).lower()))
    total = sum((l.monto_esperado for l in ordenadas if not l.es_informativo), CERO)
    return ordenadas, total


def esperado_de_turno(db, turno_id: int) -> tuple[Turno, list[LineaArqueo], Decimal]:
    turno = obtener_turno(db, turno_id)
    if turno.estado is not EstadoTurno.ABIERTO:
        raise ReglaDeNegocio(MENSAJE_CERRADO)
    lineas, total = calcular_esperado(db, turno)
    return turno, lineas, total


def _declarados_por_clave(items_declarados) -> dict[tuple, Decimal]:
    declarados: dict[tuple, Decimal] = {}
    for item in items_declarados:
        clave = clave_de(item.medio_de_pago_id, item.grupo_terminal)
        if clave in declarados:
            raise DatoInvalido("Hay un medio de pago declarado dos veces")
        declarados[clave] = item.monto_declarado
    return declarados


def _notificar_admins(db, turno: Turno, arqueo: Arqueo, lineas: list[LineaArqueo],
                      declarados: dict[tuple, Decimal]) -> None:
    diferencia = arqueo.total_declarado - arqueo.total_esperado
    fecha = f"{turno.fecha_apertura:%d/%m/%Y}"

        for l in lineas if not l.es_informativo
    ]
    cuerpo = "\n".join([

        *detalle,
    ])
    metadata = {"turno_id": turno.id, "arqueo_id": arqueo.id, "diferencia": str(diferencia),
                "usuarios": [u.id for u in participantes]}
    admins = db.scalars(select(Usuario).join(Rol, Rol.id == Usuario.rol_id)
                        .where(Rol.nombre == ROL_ADMIN, Usuario.activo.is_(True))).all()
    for admin in admins:
        db.add(Notificacion(usuario_id=admin.id, tipo=TipoNotificacion.DIFERENCIA_ARQUEO,
                            titulo=f"Diferencia en arqueo — {fecha}", cuerpo=cuerpo, metadata_=metadata))
    arqueo.notificacion_enviada = True


def registrar_arqueo(db, usuario, turno_id: int, items_declarados, total_declarado: Decimal, ip) -> Arqueo:
    """Arqueo + cierre del turno + notificaciones, todo en la transacción del
    caller. El turno va FOR UPDATE: las operaciones en curso (FOR SHARE)
    terminan antes y las que lleguen después ven el turno cerrado."""
    turno = bloquear_turno(db, turno_id)
    if turno.estado is not EstadoTurno.ABIERTO:
        raise ReglaDeNegocio(MENSAJE_CERRADO)
    lineas, total_esperado = calcular_esperado(db, turno)
    declarados = _declarados_por_clave(items_declarados)
    por_clave = {l.clave: l for l in lineas}
    if set(declarados) - set(por_clave):
        raise ReglaDeNegocio("Los medios de pago del arqueo cambiaron: volvé a cargar la pantalla.")
    for linea in lineas:
        if linea.es_informativo:
            declarados[linea.clave] = linea.monto_esperado  # decisión 10: no suma ni difiere
    faltan = [l.medio_nombre for l in lineas if l.clave not in declarados]
    if faltan:
        raise DatoInvalido(f"Falta declarar: {', '.join(faltan)}")
    suma = sum((declarados[l.clave] for l in lineas if not l.es_informativo), CERO)
    if suma != total_declarado:
        raise DatoInvalido("El total declarado no coincide con la suma de los medios")

    antes = snapshot(turno)
    arqueo = Arqueo(turno_id=turno.id, usuario_id=usuario.id, total_esperado=total_esperado,
                    total_declarado=total_declarado, created_at=ahora_db())
    arqueo.items = [ArqueoItem(medio_de_pago_id=l.medio_de_pago_id, grupo_terminal=l.grupo_terminal,
                               monto_esperado=l.monto_esperado, monto_declarado=declarados[l.clave],
                               es_informativo=l.es_informativo) for l in lineas]
    db.add(arqueo)
    turno.estado = EstadoTurno.CERRADO
    turno.fecha_cierre = ahora_db()
    turno.usuario_cierre_id = usuario.id
    db.flush()
    if total_declarado != total_esperado:
        _notificar_admins(db, turno, arqueo, lineas, declarados)
    db.flush()
    db.refresh(arqueo)  # trae las columnas generadas (diferencia)
    registrar_auditoria(db, accion="caja.arqueo_cerrado", entidad="turno", entidad_id=turno.id,
                        usuario_id=usuario.id, estado_anterior=antes,
                        estado_nuevo={**snapshot(turno), "arqueo_id": arqueo.id,
                                      "total_esperado": arqueo.total_esperado,
                                      "total_declarado": arqueo.total_declarado,
                                      "diferencia": arqueo.diferencia,
                                      "items": [{"medio_de_pago_id": i.medio_de_pago_id,
                                                 "grupo_terminal": i.grupo_terminal,
                                                 "monto_esperado": i.monto_esperado,
                                                 "monto_declarado": i.monto_declarado} for i in arqueo.items]},
                        ip_origen=ip)
    return arqueo


def obtener_arqueo(db, turno_id: int) -> Arqueo:
    obtener_turno(db, turno_id)
    arqueo = db.scalar(select(Arqueo).where(Arqueo.turno_id == turno_id))
    if arqueo is None:
        raise NoEncontrado("El turno no tiene arqueo")
    return arqueo
```

```javascript
/* Caja (/caja) y cierre de turno (/caja/cerrar/{id}). El esperado lo calcula
   SIEMPRE el backend (GET /turnos/{id}/arqueo/esperado); acá solo se muestra
   la diferencia mientras se tipea, en centavos enteros (nunca float). */
(function () {
  'use strict';

  const API = '/api/v1/turnos';

  window.cajaLogica = {
    // "1.500,50" / "1500.5" / "1500" → 150050 centavos; vacío o inválido → null.
    aCentavos: (texto) => {
      if (texto === null || texto === undefined) return null;
      let limpio = String(texto).trim().replace(/\s|\$/g, '');
      if (!limpio) return null;
      if (limpio.includes(',')) limpio = limpio.replace(/\./g, '').replace(',', '.');
      if (!/^-?\d+(\.\d{1,2})?$/.test(limpio)) return null;
      const [entero, dec = ''] = limpio.replace('-', '').split('.');
      const centavos = Number(entero) * 100 + Number((dec + '00').slice(0, 2));
      return limpio.startsWith('-') ? -centavos : centavos;
    },
    claveDe: (item) => (item.grupo_terminal ? `g:${item.grupo_terminal}` : `m:${item.medio_de_pago_id}`),
    diferencia(declarado, esperado) {
      const d = this.aCentavos(declarado);
      return d === null ? null : d - this.aCentavos(esperado);
    },
    // Suma de lo declarado en las líneas NO informativas; null si falta alguna.
    totalDeclarado(items, declarados) {
      let total = 0;
      for (const item of items.filter((i) => !i.es_informativo)) {
        const c = this.aCentavos(declarados[this.claveDe(item)]);
        if (c === null || c < 0) return null;
        total += c;
      }
      return total;
    },
    // Montos como string con 2 decimales (el backend los recibe como Decimal).
    payloadArqueo(items, declarados) {
      const aTexto = (c) => (c / 100).toFixed(2);
      return {
        items_declarados: items.map((i) => ({
          medio_de_pago_id: i.medio_de_pago_id,
          grupo_terminal: i.grupo_terminal,
          monto_declarado: i.es_informativo ? String(i.monto_esperado)
            : aTexto(this.aCentavos(declarados[this.claveDe(i)])),
        })),
        total_declarado: aTexto(this.totalDeclarado(items, declarados)),
      };
    },
  };
```
